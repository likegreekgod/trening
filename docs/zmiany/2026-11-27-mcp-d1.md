# Panel trenera w Claude, część 1: pośrednik MCP i narzędzia (PR D1, 27.11.2026)

## Zrobione

- Nowy folder `mcp/`: Worker na Cloudflare (`src/index.js`), który jest konektorem MCP dla claude.ai. Instrukcja uruchomienia jest w `mcp/README.md`.
- Logowanie: OAuth 2.1 dla Claude (`@cloudflare/workers-oauth-provider`: rejestracja klienta, PKCE, bilety w KV `OAUTH_KV`), strona zgody po polsku, potem Google tym samym klientem OAuth co panel (`access_type=offline`). Worker wpuszcza tylko adresy z `TRENER_EMAIL`. Z refresh tokenu Google bierze świeży ID token i woła `/exec` jak panel (`token`), więc `trAuth_` się nie zmienił. Gdy trener cofnie zgodę w Google, odświeżenie biletu Claude kończy grant i Claude poprosi o ponowne połączenie.
- MCP bez stanu (`src/mcp.js`: initialize, ping, tools/list, tools/call; odpowiedzi JSON, bez SSE). Błąd funkcji panelu („Ta jednostka jest już zrobiona…”) wraca jako wynik z `isError`, żeby Claude powiedział go trenerowi.
- Narzędzia (`src/tools.js`, czyste funkcje skracające odpowiedzi):
  - odczyt: `dzis` (`trPulpit`: kto trenuje, sygnały, asystent AI z pid, „Zrobił sam”, filmy bez komentarza, bloki, odpowiedzi), `klienci`, `kalendarz` (`trKalendarz`), `klient` i `jednostka` (`trKlient`: najbliższe niezrobione jednostki, ostatnie sesje z seriami jako „kg×powt. światło”);
  - zapis: `przesun` (`trPrzesun`), `zmien_plan` (`trPlan`), `decyzja_asystent` (`trPropozycja`: tak / nie z powodem / czytane / cofnij), `komentarz_sesji` (`trKomentarz`).
- Serwer: zapytanie z pośrednika ma `src: 'mcp'`. Zapisy z listy `TR_MCP_ZAPIS` trafiają do zakładki API jako „claude: trPrzesun” itd., razem z odmowami (`mcpLogRow_` z testem, `mcpLog_` w `doPost`).
- Wdrożenie: `.github/workflows/mcp.yml` (testy, test całego łańcucha `mcp/test/e2e.sh`, potem `wrangler deploy` i sekrety Workera). KV zakłada i podpina `mcp/tools/kv-id.mjs`. Bez sekretów Cloudflare krok wdrożenia jest pomijany.

## Ustalenia

- Funkcje panelu i Claude są te same (TR_FNS), więc przestawianie treningów i decyzje o propozycjach działają w obu miejscach z tą samą logiką.
- Claude nie dostaje linków klientów (z kluczem) ani linków do filmów. Filmy, RODO, klucze i linki zostają tylko w panelu.
- Karty z przyciskami w czacie (MCP Apps) to D2 (Dziś, Od asystenta AI) i D3 (Kalendarz, Jednostka, Siatka bloku, Klient).
